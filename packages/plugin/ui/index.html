Oxly Plugin — Phase 4

MCP endpoint: /mcp (Streamable HTTP, 6 project-scoped read-only tools).

Tools

  • whoami — confirm which project a key is scoped to
  • query_traces — list traces newest-first with span counts
  • get_trace — full trace with spans in replay order
  • get_span — one span: timing, status, attributes, events
  • query_security_alerts — prompt-injection / PII / anomaly alerts
  • cost_summary — per-model cost + token timeseries

Auth

Every tool takes the project SDK key (ak_...) as api_key and scopes to that project. An optional project_id must match. DEMO_MODE=true allows keyless calls with an explicit project_id for local exploration.
